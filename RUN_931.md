# Round 931: negative-vote rule validation

Round 930 motivated this ablation. Round 931 freezes 12 fresh seeds across four new scenes, with disjoint source footage. The same response bank feeds four replay arms: strict or linked-only negative votes, each with fixed or uncertainty-driven allocation. Three calls per arm is the primary budget; two, four, and five are descriptive. The Ollama model digest is pinned to the Round 930 digest.

Linked-only drops the `complete` gate on a negative vote and retains all other panel checks. A distinct verdict still requires negatives from at least two queried views and zero accumulated target votes. Unknown shots are retained. Screen all successfully generated sources using the Round 930 instructions before response collection.

For the primary comparison, hold the uncertainty allocation policy fixed and report candidate misses, exact selections, and excess planned renders. Save all source statuses and exclusions. Report any additional misses as a trade-off. A lower planned count alone does not show an improvement in end-to-end rendering. The bank contains up to eight raw calls per case; the replay budget counts the replies made available to each arm.

Run on the school worker with the existing H3/ComfyUI and Ollama services:

```bash
protocol=VideoFlow_Active_Budget/holdout_931_protocol.json
src=runs/egdr-active-source-931
bank=runs/egdr-active-holdout-931
python3 -u VideoFlow_Active_Budget/generate_sources.py --protocol "$protocol" --output "$src"
```

Fill `$src/source-screen.csv` from the generated contact sheets, using the same linked-marker criteria as Round 930. Then collect and compare:

```bash
python3 -u VideoFlow_Active_Budget/active_budget.py \
  --protocol "$protocol" --source-run "$src" --screen "$src/source-screen.csv" --output "$bank" &&
python3 VideoFlow_Active_Budget/replay_negative_rule.py \
  --protocol "$protocol" --bank "$bank" --output runs/egdr-negative-rule-931.json
```

Archive the source screen and both reports. The comparison fetches no new evidence and verifies the strict arm against the archived votes and report.
