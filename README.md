# VideoFlow

视频生成任务运行时的早期原型，探索持久化 Scene 任务、显式依赖、局部修改及中断恢复。

## 运行

Python 3.10+，无需第三方依赖：

```bash
python -m unittest discover -s tests -v
python demo.py --db demo.db
```

每次 demo 使用新的数据库。示例中 S1 → S2，S3 独立；修改 S1 后仅 S1、S2 失效，S3 的素材继续可用。

## 实现范围

- SQLite 保存场景、版本、依赖和任务；循环依赖被拒绝，下游等待上游素材。
- 修改场景会事务性创建新版本并传播至显式下游；旧任务结果不能覆盖新版本。
- 已提交任务保存外部 ID，恢复时查询原任务；未知状态保持等待，重复回调幂等处理。

## 限制

**这是单进程模拟原型，不会生成视频**，没有接入 MiniMax、ComfyUI、LLM、HTTP API、时间线、队列或对象存储。依赖由人工指定，没有自动语义推理、视觉一致性评估、真实并发调度及生产级容错。

外部提交与保存 ID 之间存在崩溃窗口。真实接入必须使用后端支持的幂等键或按客户端请求 ID 查询，配合持久 outbox、回调鉴权和故障注入测试；不能声称当前原型已避免所有重复计费。后续应实现后端适配器并测量真实延迟、成本及复用率。
